# Kalbim Sohbet

irc.kalbim.net sohbet sunucusu için basit Android sohbet uygulaması (Türkçe).

- Rumuzla bağlan (isteğe bağlı rumuz şifresi / NickServ)
- Oda listesi, arama, odaya gir/çık
- Oda içi kişi listesi, özel mesaj
- Uygulama arka plandayken bağlantı açık kalır

APK: https://github.com/42zengibar42-cell/kalbim-sohbet/releases/latest/download/Kalbim-Sohbet.apk
